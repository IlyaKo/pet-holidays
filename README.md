# Pet Holidays

Учебный проект для курса OTUS ASP.net 2024-08

## Описание

Pet Holidays - это проект, который помогает вам отслеживать и управлять бронированием гостиниц для домашних животных. С помощью этого приложения вы можете создавать и планировать бронирования, добавлять события и напоминания, а также делиться ими с другими пользователями. Проект был создан в рамках учебного курса для практики навыков разработке на актуальном стеке.

## Технологии

- **ASP.NET Core**: Используется для создания серверной части приложения, обеспечивая надежность и масштабируемость.
- **Entity Framework Core**: Используется для работы с базой данных, обеспечивая эффективное управление данными.
- **JavaScript**: Используется для разработки интерактивного интерфейса клиента.
- **React**: JavaScript-библиотека для построения пользовательских интерфейсов, используется для создания динамичных и отзывчивых компонентов.
- **Docker**: Используется для контейнеризации приложения, обеспечивая его портативность и легкость развертывания.
- **SQL Server**: Используется в качестве системы управления базами данных для надежного хранения данных.
- **JWT (JSON Web Tokens)**: Используется для аутентификации и авторизации пользователей.

## Установка и запуск

1. Клонируйте репозиторий:
    ```bash
    git clone https://github.com/IlyaKo/pet-holidays.git
    ```

2. Перейдите в директорию проекта:
    ```bash
    cd pet-holidays
    ```

3. Соберите и запустите проект с помощью Docker:
    ```bash
    docker-compose up --build
    ```

4. Откройте браузер и перейдите по адресу `http://localhost:5000`, чтобы увидеть работающий проект.
